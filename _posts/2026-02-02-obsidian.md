A bit unfortunately I am forced to multitask a lot at work. That slowly projected into some missed tasks, finding where I ended with others and also feeling that I am not doing much. Sometimes I also struggled with communication, because our company policy clears your emails and IM after just half year. I thought what to do about it and decided to start a journal of my work.

I started small with a single text file in [Markdown][1]. It looked like this:

```markdown
# Journal

## 2025-07-10 Thu

### Some Activity

John provided me with following files in CSV format:

- `input1.txt`
- `input2.txt`

Created a project in `d:\Gitlab\SomeActivity` and built small prototype. 
Generated output file and provided it to John. His feedback was:

- The data in column 3 should be separated by comma

...

# Acronyms

*[CSV]: Comma-Separated Values
```

This worked for me quite nicely and provided all benefits I was looking for. It allowed me to focus on a task, make sure I have the steps and communication documented. Other good thing was a peace of mind that I have a record where I ended and what I already tried.

About half a year later, my journal had over 250kB and 5000 plus lines of text. It started to be a bit clumsy and repetitious. When I looked for alternative approached, I run into [Obsidian][2]. The application is also built around Markdown, but works on a directory (they call it a vault) of those files. The Obsidian indexes all those files, allows easy linking between them and nice search. 

![Obsidian](/img/obsidian.png)

The Obsidian is very configurable. Here are some things I setup for me. The configuration is stored in the vault in the directory `.obsidian`, so if you copy your vault, all settings go with you.

## Themes

I use [Minimal][3] theme. To be able to fine-tune the theme, there is also a plugin called **Minimal Theme Settings** that allows to change many details. I use `Atom` variation with Colorful headings.

## Plugins

There are many plugins available and I tried only few ones. I am generally trying to keep things simple and minimal. Main benefits were already there when I started the journal. Here are ones that I found useful. 

### Calendar

Simple calendar that refer to daily notes. It makes it easy to return to previous day notes. On each day there is an indication on how much text there is in the daily note.

### File Explorer Note Count

Trivial plugin that shows number of notes in each directory. 

### Omnisearch

Full-text search in note texts. Very useful as normal switcher only search over note names and properties.

### Various Complements

Good auto-complete. Helps with links and all other text in the note.

### Image Converter

One thing I noticed quite soon is that Obsidian allows you to place the image into the note and automatically put it into resources and link it from there. It is all good, but it creates `.png` images that are rather huge and use rather boring numeric name. This plugin allows you to rename the image, convert it to different formats and some other goodies.

### Tasks

Last plugin is helping with tasks. You can create an entry for task checkbox in any note and mark it as done. This plugin helps you to show aggregated list of all such tasks, with grouping, filtering and others. You just need to place a code block like this in your note:

    ```tasks
    not done
    has due date
    group by due
    ```

This block will be automatically replaced by all tasks from any not-done note with due date grouped by a due date. See its [documentation][4], it has plenty of options while still being very simple.

## Structure

I use only top level directories and there are only few of them:

- `Log` - daily notes named like `2025-07-10 Thu`
- `Notes` - any note that does not belong to other category
- `People` - notes representing individuals
- `Resources` - images, files, etc
- `Templates` - few templates for a note. Useful for meeting minutes and other regular entries
- `Tools` - projects I work on

On the top level I also keep few organizational notes, home note and bases that filters my notes according to a criteria.

## Conclusion

I am using the Obsidian for last few months and so far I am pretty happy with how it works. In some upcoming posts I will also touch how I generate some notes from external sources - sharepoint, repositories, etc.
